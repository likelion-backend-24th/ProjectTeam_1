# 🌱 CityFarm (도시농업 플랫폼)

> Java 및 Spring Boot 기반의 텃밭 분양 및 커뮤니티 서비스입니다.

---

## 🛠 백엔드 기술 스택
- **Backend:** Java 21, Spring Boot, Spring Security, Spring Data JPA, MySQL
- **Infra & DevOps:** AWS EC2, Docker, Git

---

## 💻 프론트엔드 기술 스택
- **Framework:** React / Next.js
- **Styling:** Tailwind CSS
- **State Management:** Zustand

---

## 🚀 배포 및 아키텍처
- **Cloud Provider:** AWS EC2
- **Containerization:** Docker 및 Docker Compose를 활용한 빌드 및 배포
