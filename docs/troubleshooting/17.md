# 사례 17 - 카드 등록 중 인증문자 미발송

## 📌 문제 발생

1. 구독을 위한 카드 결제 진행 중 인증문자 미발송

---

## 🔍 기대 결과

- 테스트 계정에서 사용되는 카드 번호나 인증번호로 등록 필요한 걸로 생각
- 백엔드 로그를 조회 해보니 빌링키 발급 확인 시 PortOne 조회 지연으로 발생하는 문제로 추정

---

## 🔍 원인 분석

- 어떤 코드/구조에서 문제가 있었는가?
    - PortonePaymentClient.java에 빌링키 조회 메서드

---

## 🛠 해결 방법

- 어떻게 해결했는가?
    
    PortOne API 빌링키 조회 재시도 추가
    
    프론트에서 SDK 발급 응답을 받은 직후 바로 조회하면, PortOne 쪽에 빌링키가 아직 반영되기 전이라 404(BILLING_KEY_NOT_FOUND)가 날 가능성으로 
    
    짧게 재시도 하는 로직 추가했는데도 해결 되지 않았는데
    
    포트원 API에 요청 파라미터에 storeId를 누락하고 있어서 추가
    
    storeId 없이 조회시 결제가 실제로 성공했어도 항상
    
    PAYMENT_NOT_FOUND로 착각하고 있었음.
    

---

## 🧠 배운점

- 트러블 슈팅을 통해 깨달은 부분
    - api 문서를 계속 보면서 코드를 작성해야 해야겠다
